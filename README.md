# picture-book-creator · AI 绘本创作大师

> 一句话：给它一个主题，它还你一本**画风全书统一**的绘本（单文件 HTML，离线可翻）。

WorkBuddy 技能包，也可作为通用绘本创作方法论使用（提示词模板、质检清单对其他生图工具同样适用）。

---

## 为什么需要这个技能

用 AI 画绘本，最容易翻车的不是单张图好不好看，而是**一本书画下来像五个人画的**：角色漂移、画风打架、道具前后不一致。

本技能用**四层风格锁定体系**解决这个问题：

| 层 | 机制 | 作用 |
|----|------|------|
| ① | **STYLE-BLOCK 冻结** | 全书共用一个一字不改的风格块（媒介 + 笔触 + 色温 + 纸纹） |
| ② | **NEGATIVE-BLOCK 压制** | 负向词库压住漂移形态（3D 感、厚涂、高饱和、恐怖化…） |
| ③ | **图生图锚定工作流** | 第一张封面 = 定妆照 + 风格锚点 + 比例基准三重身份，后续每页以它为参考图 |
| ④ | **质检风格一致性第一优先项** | 色温 / 笔触 / 纸纹 / 对比度四维逐张过检 |

多角色绘本另用**角色锚点链**：新角色首次登场的那一页即成为该角色的锚点页，不全书单锚封面。

## 四种画风

| 模板 | 画风 | 适合年龄 | 状态 |
|------|------|---------|------|
| A | 低幼水彩暖萌风 | 2-5 岁 | ✅ 已实战 2 本 |
| B | 写实水彩怀旧风 | 6-12 岁 | 未实战 |
| C | 水墨淡彩国风 | 全年龄 | ✅ 已实战 1 本 |
| D | 扁平卡通风 | 3-6 岁 | 未实战 |

每套模板都配齐冻结 STYLE-BLOCK、负向词、封面专用 prompt、hex 色板。换画风只换 STYLE-BLOCK，一致性机制不变。

## 使用方式

### 在 WorkBuddy 中

1. 安装技能后，直接说主题即可，例如「做个睡前绘本，主角是怕黑的小白兔」
2. 技能会**先出分页文字稿**等你确认，通过后才开始生图
3. 完成后交付单文件 HTML（图片 base64 内联，双击即开，可离线、可分享）

### 只用方法论

不看 SKILL.md 也行，直接读 `references/prompt-templates.md` 抄三段式公式：

```
[STYLE-BLOCK 冻结] + [当页场景] + [CHARACTER-BLOCK 冻结] + [质量后缀] + [NEGATIVE-BLOCK]
```

## 文字排版：横版底部带是母语

这是三轮实战反馈砸出来的结论：

> **文字要像画在纸上，不能像贴在纸上，更不能挂在角上。**

| 排版 | 观感 | 结论 |
|------|------|------|
| 底部横版渐变带 | 文字沿画面下缘的"地平线"横铺，长在画面里 | ✅ 默认，全书统一 |
| 四角浮字 | 再淡也是"一块字挂在角上" | 仅例外页 |
| 不透明白底卡片 | 像块补丁贴在水彩画上 | ❌ 禁用 |

## 组装注意（给开发者）

模板的 `coverImage` 和 `pages[].image` 字段**不含 data URI 前缀**，组装时 base64 必须带前缀：

```python
def b64(fp):
    return 'data:image/png;base64,' + base64.b64encode(open(fp, 'rb').read()).decode()
```

漏了前缀 → 浏览器把纯 base64 当相对 URL → 全图黑屏（`ERR_INVALID_URL`）。详见 `references/common-pitfalls.md` 问题 13。
