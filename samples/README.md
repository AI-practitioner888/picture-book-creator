# 实战样书

三本全部由 `picture-book-creator` 技能实跑产出，未做任何人工修图。
图片为 1024×1536 JPEG（原图 PNG 体积过大，已压缩以便在线浏览），文字版式与原版一致。

## 小棉花和月亮灯

- 画风模板：低幼水彩　页数：8　定位：睡前情绪 · 3-5 岁
- 小棉花怕黑，月亮灯陪它入睡。8 页全 bottom 布局终版，三轮版式迭代的定型样本。
- 在线翻页：[samples/moonlight/](samples/moonlight/)（需先开启 GitHub Pages）
- 离线单文件（内嵌原图，25-34MB）：见本地 `outputs/moonlight/`，不入库

## 小红帽智斗大灰狼

- 画风模板：低幼水彩　页数：10　定位：经典改编 · 5-7 岁
- 温和智慧版：无惊吓，小红帽用热茶计和晾衣绳识破大灰狼。10 页，多角色锚点链样本。
- 在线翻页：[samples/red-riding-hood/](samples/red-riding-hood/)（需先开启 GitHub Pages）
- 离线单文件（内嵌原图，25-34MB）：见本地 `outputs/red-riding-hood/`，不入库

## 小墨滴和文房四宝

- 画风模板：水墨国风　页数：8　定位：国学启蒙 · 4-7 岁
- 水墨国风模板首跑，小墨滴认识笔、墨、纸、砚。8 页，繁体「學」字正确渲染。
