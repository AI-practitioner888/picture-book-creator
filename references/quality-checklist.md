# 绘本质检清单

交付前的标准化检查流程，避免低级错误流出。
按顺序逐项检查，有问题的页面标记后统一修改。

---

## 检查总览

| # | 检查项 | 必查 / 选查 | 检查时机 |
|---|--------|:----------:|---------|
| 1 | 风格一致性 ⭐ | ✅ 必查 | 全部生图完成后 |
| 2 | 角色一致性 | ✅ 必查 | 全部生图完成后 |
| 3 | 文字密度 | ✅ 必查 | 内容撰写完成后 |
| 4 | 相邻页区分度 | ✅ 必查 | 生图完成后 |
| 5 | 年代穿帮 | ⚠️ 历史题材必查 | prompt 写完后 + 生图后 |
| 6 | 图文匹配 | ✅ 必查 | 生图完成后 |
| 7 | 比例尺寸 | ✅ 必查 | 生图完成后 |
| 8 | 文字可读性 | ✅ 必查 | HTML 制作完成后 |
| 9 | 结尾完整性 | ✅ 必查 | 内容撰写完成后 |

---

## 1. 风格一致性检查 ⭐（v2 新增，第一优先级）

**检查目的**：确保全书每一页的色温、笔触、纸纹、对比度统一，
不会出现"角色一样但每页像不同人画的"的漂移问题。

**检查要点（四个维度，逐一扫）**：

| 维度 | 看什么 | 漂移的表现 |
|------|--------|-----------|
| 色温 | 全书整体冷暖是否一致 | 有的页偏黄、有的页偏蓝 |
| 笔触 | 线条/涂抹的质感是否一致 | 突然出现厚涂、或变得干净矢量 |
| 纸纹 | 材质基底是否一致 | 某几页纸纹消失，变"数码感" |
| 对比度 | 明暗节奏是否一致 | 某页突然变灰、或突然变艳 |

**快速检查法（三秒法）**：
把所有页缩略图拖到同一文件夹，切到缩略图视图（或拼图），**眯眼看整体**：
- 健康的书：远看是一本书，色调气质统一，近看每页内容不同
- 漂移的书：远看就五彩斑斓、明暗交错，像拼贴画

**修复方法**（按漂移严重程度）：
1. 轻微漂移（1-2 页）→ 用第一张定妆照做参考图，图生图重画该页
2. 中度漂移（3-5 页）→ 检查这些页的 prompt 是否误改了 STYLE-BLOCK 或漏附负向词，修正后重画
3. 重度漂移（过半页面）→ 停止出图，重新冻结 STYLE-BLOCK，从定妆照开始整书重锚

**预防**：见 `references/prompt-templates.md` 通用技巧第 5 条「风格锚定工作流」，
以及 `references/common-pitfalls.md` 问题 11。

## 2. 角色一致性检查

**检查目的**：确保主角在每一页的形象统一，不会出现"换了一个人"的情况。

**检查要点**：

| 检查维度 | 具体内容 |
|---------|---------|
| 服装 | 衣服颜色、款式、花纹是否一致？有没有突然换衣服？ |
| 发型 | 发色、发型、发饰是否一致？ |
| 肤色 / 毛色 | 人物肤色、动物毛色是否统一？ |
| 体型 | 高矮胖瘦有没有明显变化？ |
| 面部特征 | 眼睛大小、脸型、标志性特征（如雀斑、伤疤）是否一致？ |
| 配饰 | 眼镜、围巾、帽子等配饰是否每一页都有？ |

**快速检查法**：
把所有页面缩略图排在一起（可用系统预览或拼图工具），快速扫一遍主角，
如果有某一页看起来"不像同一个角色"，就是有问题。

**常见问题 & 修复**：
- 某一页角色发色变了 → 用图生图模式，以上一页为参考重画
- 角色忽高忽矮 → 检查 prompt 中是否有导致比例变化的词
- 动物品种变了（如兔子变猫）→ 角色描述块不够详细，强化特征后重画

## 3. 文字密度检查

**检查目的**：确保每页文字量符合目标年龄段的认知能力。

**检查要点**：

| 年龄段 | 每页字数范围 | 检查标准 |
|:-----:|:----------:|---------|
| 2-3 岁 | 15-40 字 | 超过 40 字=过多，低于 10 字=过少 |
| 3-5 岁 | 30-80 字 | 超过 80 字=过多，低于 20 字=过少 |
| 5-7 岁 | 50-120 字 | 超过 120 字=过多，低于 30 字=过少 |
| 8-12 岁 | 80-200 字 | 超过 200 字=过多，低于 50 字=过少 |

**检查方法**：
逐页统计正文字数（不含标点、页码），超出范围的页面标注后精简或扩充。

**额外检查**：
- [ ] 低幼段（2-5 岁）是否有叠词、拟声词增加童趣？
- [ ] 长句是否适合朗读（一口气能读完吗）？
- [ ] 有没有生僻字（低幼段尤其注意）？

---

## 4. 相邻页区分度检查

**检查目的**：避免相邻两页画面雷同，读者翻页后感觉"没变化"。

**检查要点**：

每一组相邻页（P1&P2, P2&P3, ...），检查是否至少在 **2 个维度** 上有明显不同：

| 维度 | 不同的表现 |
|------|-----------|
| 构图距离 | 特写 vs 远景、近景 vs 全景 |
| 时间/光线 | 白天 vs 黄昏、室内暖光 vs 室外冷光 |
| 场景类型 | 室内 vs 室外、山上 vs 水里 |
| 天气/季节 | 晴天 vs 下雨、夏天 vs 冬天 |
| 氛围情绪 | 紧张 vs 宁静、热闹 vs 孤独 |
| 人物数量 | 单人 vs 多人、主角特写 vs 群像 |

**检查方法**：
相邻两页并排对比，快速判断："如果只看缩略图，能一眼看出是两页吗？"
如果答案是"不能"或"勉强能"，就需要修改其中一页的 prompt。

**常见问题场景**：
- 连续多页都是同一个房间 → 用特写/远景切换、光线变化来区分
- 连续多页都是户外走路 → 换天气、换角度、换景别
- 连续多页都是对话场景 → 交替使用特写表情和全身动作

---

## 5. 年代穿帮检查

**⚠️ 仅历史背景绘本必查，现代题材可跳过**

**检查目的**：确保特定年代的绘本中不会出现不符合时代的物品。

**检查要点（以中国乡村 1960s-1980s 为例）**：

| 类别 | 不该出现的 | 应该出现的 |
|------|-----------|-----------|
| 建筑 | 水泥楼房、瓷砖、玻璃窗、防盗门 | 土坯房、茅草顶、木格窗、纸糊窗 |
| 服装 | 牛仔裤、T恤、运动鞋、塑料凉鞋 | 粗布衣裳、补丁、布鞋、军绿/藏青色 |
| 道具 | 塑料用品、电子产品、不锈钢餐具 | 油灯、粗瓷碗、木桌、竹篮、麻袋 |
| 交通 | 汽车、摩托车、自行车（后期才有） | 牛车、步行、渡船、独轮车 |
| 环境 | 柏油路、电线杆、路灯 | 土路、水井、麦秸垛、夯土墙 |

**检查方法**：
1. 写完 prompt 后扫一遍关键词，确认没有现代元素
2. 出图后逐张检查，重点看背景和边角（AI 常在角落里塞现代物品）

## 6. 图文匹配检查

**检查目的**：确保画面准确表达了文字描述的核心情节，不会"图不对文"。

**检查要点**：

逐页对照文字内容和画面，确认：

- [ ] **核心动作**：文字描述的主要动作，画面里有吗？
  - 例：文字写"小明把苹果递给奶奶" → 图里要有递的动作，不能只是站着
- [ ] **空间关系**：文字描述的位置关系，画面表达对了吗？
  - 例：文字写"河对岸的小兔" → 小兔应该在对岸，不能在同一边
- [ ] **关键物品**：文字中提到的重要道具，画面里有吗？
  - 例：文字写"拿着一把红色的伞" → 伞必须是红色的、拿着的
- [ ] **情绪表情**：文字描述的情绪，画面角色脸上有吗？
  - 例：文字写"伤心地哭了" → 角色表情要悲伤，不能笑着
- [ ] **数量正确**：文字写"三只小鸟" → 画面里不能是两只或四只

**常见图文不匹配场景**：
- "隔河相望" → 两个人都在河里
- "爬上山顶" → 人还在半山腰
- "送礼物" → 两个人都空手
- "夜晚" → 画面像白天

## 7. 比例尺寸检查

**检查目的**：确保画面中物体大小合理，不会出现"房子像狗窝""碗比头大"等问题。

**检查要点**（详见 `size-proportion-lexicon.md`）：

快速校验 3 个最容易出错的维度：

### 6.1 房屋 & 门
- 门的高度 ≈ 1个成人高 ✓
- 房子高度 ≈ 2-3个成人高 ✓

### 6.2 家具
- 桌子高度 ≈ 成人腰高 ✓
- 椅子坐面 ≈ 成人膝盖高 ✓

### 6.3 交通工具
- 船的大小能坐下人物吗？ ✓
- 车/轿子和人的比例合理吗？ ✓

**详细自检清单见 `size-proportion-lexicon.md` 文末。**

## 8. 文字可读性检查

**检查目的**：确保 HTML 绘本的文字浮层清晰可读，不遮挡关键画面。

**检查要点**：

- [ ] **文字清晰度**：文字颜色和背景对比度够吗？小字能看清吗？
- [ ] **遮挡情况**：文字浮层有没有遮住画面的关键部分（主角脸、核心动作）？
- [ ] **行数适中**：单页文字会不会太多，浮层占满了半张图？
  - 建议：底部浮层不超过画面高度的 1/3
- [ ] **字号适配**：手机上能看清吗？（用手机模式预览或缩小窗口测试）
- [ ] **特殊样式**：对话气泡位置合理吗？会不会挡住角色？
- [ ] **封面书名**：封面书名位置合适吗？有没有挡住关键画面元素？

**常见问题 & 修复**：
- 文字浮层遮住主角脸 → 调整文字位置（改用侧边卡片样式或 split 分栏样式）
- 文字太暗看不清 → 加深背景渐变、增加文字描边或阴影
- 文字太多浮层太高 → 精简文字，或改用 split 分栏样式（上图下文）

## 9. 结尾完整性检查

**检查目的**：确保故事有完整的收束，寓意传达到位。

**检查要点**：

- [ ] **故事有结局**：最后一页是故事的终点，不是中途戛然而止
- [ ] **情绪有收束**：结尾情绪是平和/温暖的（尤其低幼绘本，避免开放式结尾让孩子不安）
- [ ] **寓意能感知**：教育意义/寓意是否通过故事自然传达，而不是说教？
- [ ] **呼应开头**：结尾和开头有呼应吗？（如开头出门→结尾回家，开头好奇→结尾满足）
- [ ] **封底有仪式感**：最后一页（封底）有"完""晚安"等结束提示吗？

**低幼绘本额外检查**：
- [ ] 结尾是否温暖安心（适合睡前阅读）？
- [ ] 有没有"回家""睡觉""晚安"等收尾元素？

**科普/教育类额外检查**：
- [ ] 知识点讲清楚了吗？
- [ ] 有没有总结性的页面帮助孩子回顾？

## 质检流程建议

建议按照以下顺序检查，效率最高：

```
内容完成后
    ↓
1. 文字密度检查（数字数就行，最快）
2. 结尾完整性检查（看大纲和最后几页）
    ↓
生图完成后
    ↓
3. 风格一致性检查（缩略图整体扫，第一优先级）
4. 角色一致性检查（缩略图排列扫视）
5. 相邻页区分度检查（相邻并排对比）
6. 图文匹配检查（逐页对照文字和图）
7. 比例尺寸检查（重点看房屋/家具/车船）
8. 年代穿帮检查（历史题材）
    ↓
HTML 制作完成后
    ↓
9. 文字可读性检查（浏览器预览，手机模式也看一下）
```

**全部检查通过后再交付。** 发现问题不要怕返工——早发现早修改成本最低。
**风格一致性未通过时，修复优先级高于其他所有检查项**：风格漂移是整书性的，
修一本书的画风比修十页图文匹配贵得多。
